# Todo List

A simple Todo List web application that allows users to add, delete, and search for tasks. The app is built using **HTML, CSS (Bootstrap), and JavaScript**.

## Features
- Add new todos
- Delete existing todos
- Search and filter todos
- Responsive design using Bootstrap

## Technologies Used
- **HTML5**: Markup structure
- **CSS3**: Styling using Bootstrap
- **Bootstrap 4.3.1**: Responsive UI framework
- **JavaScript (ES6)**: Functionality for adding, deleting, and filtering todos
- **FontAwesome 5.7.2**: Icons for delete functionality

## Installation & Usage
### 1. Clone the Repository
```sh
git clone https://github.com/Devsalmasaeed/todo-list.git
cd todo-list
```

### 2. Open in Browser
Simply open the `index.html` file in your browser.

### 3. Customize
- Modify the `styles.css` file to update styles.
- Edit `app.js` to add additional functionality if needed.

## File Structure

